# Portfolio

## Deploy to GitHub Pages

This project deploys to GitHub Pages automatically when you push to the
`main` or `master` branch.

1. Push this project to a GitHub repository.
2. In the repository, open **Settings → Pages** and set **Build and deployment**
   to **GitHub Actions**.
3. Push to `main` (or `master`) and check the **Actions** tab for the deployment.

For a project repository, the site URL will be
`https://<owner>.github.io/<repository>/`. For a repository named
`<owner>.github.io`, it will be `https://<owner>.github.io/`.
